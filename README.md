# Gemini Web OpenAI-Compatible Proxy (Render)

This service drives Gemini Web through a browser session. It is not the official Gemini API.

## Render deployment

- Runtime: Docker
- Plan: Free
- Health check: /health
- No persistent disk is configured; Render Free filesystems are ephemeral.

After deployment, open the Render service Environment page and add:

- GEMINI_COOKIES: a fresh cookie export for a Google account signed in to Gemini Web. Accepted formats: Playwright cookie JSON, Netscape cookie jar, or a Cookie request-header string.
- API_KEY: generated by Render at service creation.

Never commit cookies to this repository. Rotate/revoke any cookie previously committed to a public repository.

## API

- GET /health (no authentication; intended for monitoring)
- GET /v1/models
- POST /v1/chat/completions

Send Authorization: Bearer YOUR_API_KEY on API requests.

Example:

    curl https://YOUR-SERVICE.onrender.com/v1/chat/completions \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -H 'Content-Type: application/json' \
      -d '{"model":"gemini-web","messages":[{"role":"user","content":"Hello"}]}'

The browser session is loaded at startup. If it expires, replace GEMINI_COOKIES in Render Environment and redeploy. /health reports initializing until a valid session is detected.

## UptimeRobot

Create an HTTP(s) monitor for https://YOUR-SERVICE.onrender.com/health. Use it for uptime alerts. Render Free services may sleep when idle; monitoring does not guarantee continuous runtime.
